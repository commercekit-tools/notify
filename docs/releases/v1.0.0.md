# CommerceKit Notifications v1.0.0 — draft

Initial public GitHub Action release for provider-neutral CommerceKit workflow notifications.

- Defines NotificationEvent v1 and its JSON Schema for check, CCv2 build, and CCv2 deployment events.
- Renders semantic event templates to Slack Incoming Webhooks with Block Kit and Microsoft Teams Workflows with Adaptive Cards.
- Validates event data and HTTPS action links, masks webhook URLs, redacts common credential patterns, bounds payloads, and blocks redirects.
- Retries transient delivery failures up to two times with ten-second request timeouts and bounded `Retry-After` support.
- Keeps notification delivery failure non-fatal by default; `fail-on-notification-error: true` makes delivery failure fail the step.
- Establishes the event output contract for future CommerceKit CCv2 build/deploy Actions and reusable workflows.

The legacy `sap-cx-actions` build/deploy Actions remain unchanged and do not emit NotificationEvent v1. Email and new CCv2 producer Actions are outside this release.

Publication and Marketplace listing are pending manual provider smoke and owner release validation.
